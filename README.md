# 상속분 프로그램 — 축소형 V1

기본 상속분 계산과 PDF 원문 열람·직접 추출·한국어 OCR 후보 검토를 한 로컬 HTML에서 사용하는 **가공 사례 전용 통합 시제품**입니다. 축소형 V1 개발은 2026-10-26에 마감했습니다. 실제 사건 처리용 완제품 또는 일반적인 법률 계산기가 아닙니다.

## 설치 없이 실행하기

전달받은 HTML을 Microsoft Edge 창에 끌어 놓거나 ‘연결 프로그램 → Microsoft Edge’로 엽니다. `file://` 방식으로 실행하며 인터넷, Node.js·npm·Python·Git·Codex 설치, 개발 서버가 필요하지 않습니다. 회사 정책이 실행을 제한하면 보안을 완화하지 말고 중단합니다.

현재 개발 Mac에 보존된 최종 파일은 `experiments/lite-v1-workbench/generated/lite-v1-3.html`입니다. 생성 스크립트의 기본 출력명은 `lite-v1.html`입니다. 이름이 달라도 아래 SHA-256이 같아야 같은 시험본입니다. Git에서 생성물과 모델을 제외하므로 GitHub 소스만 내려받으면 사용자 실행 파일까지 준비되는 것은 아닙니다.

| 전달 파일 | 역할 |
|---|---|
| `lite-v1-3.html` (재생성 시 `lite-v1.html`) | C1 계산·PDF·OCR 자원을 포함한 실행 파일 |
| `NOTICE.txt` | 포함 라이브러리·모델의 라이선스 고지; HTML과 함께 전달 |
| [최종 제출 안내](docs/inheritance/LITE_V1_FINAL_HANDOVER.md) | 프로젝트 소개·실행·검증·사용 제한; 사본을 함께 전달 |
| `Windows-시험안내.txt` | 기존 상세 시험 절차와 당시 이력; 최종 상태는 제출 안내 참조 |
| 가공 PDF 및 `OFL-NotoSansKR.txt` (선택) | 시험 표본과 포함 글꼴의 재배포 고지 |

HTML은 **9,477,720바이트**이며 SHA-256은 다음과 같습니다.

```text
2963016205768fdca0e6bdbf5b2711f3a32218edf4202b42349f158ad844581c
```

## 기능과 고정 범위

- PDF 선택·페이지 이동·canvas 원문 표시·직접 텍스트 추출·명시적 한국어 OCR 실행·후보 수정.
- 추출/OCR/수정 후보는 NEEDS_REVIEW입니다. 원문과 대조해야 하며 법적 사실·상속인으로 자동 확정하지 않습니다. C1 필드 자동 입력도 없습니다.
- C1은 승인된 **가공 표본과 그 승인 조건 안의 제한 입력**만 계산합니다. 배우자+생존 성년 친생자녀, 배우자+생존 성년 친생부모, 배우자 없는 생존 성년 친생자녀의 세 유형입니다.
- 사망 개시일 **2017-01-10**, 결과 기준일 **2017-01-11**, 법령 **BL1-LAW-2016-14409**에 한정합니다. 다른 날짜를 같은 법률로 확장하지 않습니다.
- 정확한 분수·Q 보존·UNKNOWN 구분·BLOCKED/ERROR/STALE·입력 변경 시 이전 결과 및 복사 무효화·최신 결과 복사/선택 대안을 유지합니다.
- R04 대습·R05 연속상속은 **PENDING**입니다. M2 기술 기반은 보존하지만 정상 배분은 비활성입니다. 과거법·상속포기·입양·복수 사건·미지원 관계는 정상 계산 대상이 아닙니다.

## 가공 PDF로 시험하기

1. HTML을 Edge로 열어 PDF와 C1 초기화 READY를 확인합니다.
2. `experiments/offline-ocr/fixtures/text-only.pdf`를 선택해 원문과 직접 추출 후보를 확인합니다.
3. 같은 폴더의 `scan-only.pdf`를 선택하고 한국어 OCR을 명시적으로 실행합니다. 후보를 원문과 대조·수정합니다. 인명 누락을 성공적인 사실 확정으로 해석하지 않습니다.
4. `experiments/lite-v1-workbench/generated/fixtures/three-pages.pdf`로 페이지 이동과 문서 교체 시 이전 후보 제거를 확인합니다. 이 파일은 생성물이며 없으면 개발 환경에서 `fixtures.py`로 준비합니다.
5. C1의 가공 표본을 불러와 계산하고 입력 수정 시 옛 결과가 제거되는지 확인합니다. 최신 결과는 복사 버튼 또는 결과 선택 후 Edge 복사 메뉴/Ctrl+C로 복사합니다.

실제 제적등본·개인정보·사건자료는 입력하거나 GitHub에 올리지 않습니다. PDF 한도는 8 MiB·10쪽·렌더 400만 화소이며 모든 PDF/전체 메모리 안전을 보장하지 않습니다. 원문·후보는 자동 저장하지 않지만 OS/브라우저 복구·클립보드의 안전 삭제를 보장하지 않습니다.

## 검증 상태와 중요한 제한

2026-10-26 회사 Windows **Edge 104.0.1293.47**에서 사용자가 수정본을 실행하고 **“이제 잘 된다”**고 보고했습니다. 이는 사용자 실행 성공 확인이며, PDF 페이지 이동·OCR 인식률·복사 등 개별 항목의 Windows PASS 또는 전체 자동시험 통과가 아닙니다.

같은 HTML의 기존 자동시험은 Mac Chromium104·최신 Mac Chromium·Mac Edge에서 각각25개 통과했습니다. API 제거 보조 시험25개, C1/M2 Node135개, 빌드7개, 기존 브라우저별 회귀88개도 통과했습니다. 이번 마감에서는 기록·해시·고지·문서만 점검했으며 기능 시험을 새로 실행하지 않았습니다.

**실제 사건·업무 판단 사용은 금지합니다.** PDF.js4.2.67 legacy는 구버전으로 보안·유지보수 한계가 있습니다. 한국어 OCR은 기존 가공 표본 **CER32.84% 및 인명 누락**이 있으며, 한자·세로쓰기·복잡한 제적등본 품질은 합격이 아닙니다. 사용자 실행 성공은 법률·보안·정확도·개인정보 처리 승인으로 확대되지 않습니다.

## 개발용 재생성·문서

사용자 PC에서는 다음 명령이 필요하지 않습니다. 기존 개발 Mac에서 고정 자원과 기존 C1 출력이 준비된 경우에만 실행합니다.

```sh
node experiments/lite-v1-workbench/compat/prepare.mjs
node experiments/lite-v1-workbench/build.mjs
```

자원 준비·공식 출처·SHA 검증은 [호환 자원 안내](experiments/lite-v1-workbench/compat/README.md)를 따릅니다. 누락 자원은 빌더가 자동 다운로드하지 않습니다. 출력은 `generated/lite-v1.html`, `NOTICE.txt`, `Windows-시험안내.txt`입니다. 재생성 뒤 `results/build.json`과 해시를 대조합니다. 기존 정상 HTML을 덮어쓸 필요 없이 보존할 수 있습니다.
