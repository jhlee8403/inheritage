# 검증 계획과 정답 후보

작성일: 2026-10-18. 아래 시험은 계획이며 엔진·OCR·Edge 시험을 수행한 결과가 아니다. **정답 후보의 법률 승인 상태는 모두 PENDING**이다. 합격 수치를 통과했다고 법률 승인·업무 배포 승인으로 간주하지 않는다.

## 독립 정답 절차

구현 결과를 보기 전에 가공 사실관계, 자료의 완전성, 사건별 날짜·적용법 후보, 가정, 출처, 제외 이유, 중간 가지 지분, 최종 귀속자·지분·미해결분을 고정한다. 법률 검토자가 규칙과 후보를 검토하고 별도 검산자가 산술을 확인한다. 동일한 추정으로 코드와 정답을 만든 뒤 일치만으로 검증하지 않는다. 후보 변경은 사유·원래 값·검토 이력을 남긴다.

사례 레코드는 ID, 데이터 버전, 가공 자료 식별자, 규칙 버전, 전제, 사건열, 기대 경로/상태/지분, 법률 승인, 산술 검산, 소프트웨어 실행, 업무 환경 실행의 독립 상태를 갖는다. 미확정 기대값은 숫자로 채우지 않고 ‘검토 보류’로 둔다.

## 수치 후보 — 구현 전 가공 사실

각 후보는 해당 상속인 집합이 완전하고 혼인·친자·포기·결격·상실 등이 명시적으로 확인된 것으로 가정한다. 과거 관계나 특별수익·기여분·유증 등은 없다는 전제를 별도로 둔다. ‘없음’은 문서 미발견의 뜻이 아니다.

## 산술·무결성 시험 제안

기약화·정수 범위 초과·0/음수 분모 입력 거부·합산 순서 불변·유효 경로 곱·시작 지분 비례·입력 순열에 따른 결과 불변을 검사한다. 변형 시험은 ID 재명명·자료 나열 순서를 바꿔도 같은 관계/경로 결과여야 한다. 지분 보존은 단계별·전체에서 검사하되 귀속자와 법적 경로가 틀렸는데 합계만 맞는 오류를 통과시키지 않는다. 잘못된 parent 참조·관계 순환·중복 경로·미지원 스키마·훼손·과도한 파일도 별도 시험한다.

## 문서 추출·전체 흐름·오프라인

추출 정확도는 OCR_EVALUATION_PLAN의 가공 표본을 사용한다. 직접추출·혼합 영역 분류, OCR의 높은 점수에도 틀린 이름/일자/관계, 깨진 텍스트층·인식 중복, 회전 후 원문 좌표, 취소·재시도를 각각 비교한다. 법률 엔진에는 별도로 확정한 구조화 사실만 넣어 OCR 오류와 계산 오류를 분리한다.

전체 흐름은 PDF 선택 → 후보/근거 보기 → 사용자 확정·병합/분리 → 계산/보류 → 수정 후 재계산 → 경고 포함 텍스트 선택·복사 → 명시적 저장 → 종료·재실행·원문 재연결로 구성한다. 브라우저 종료 후 사건 자동 복원·숨은 영구저장이 없는지 저장소를 점검한다. 명시적 저장 파일·클립보드의 자동 삭제를 약속하지 않는다.

깨끗한 Edge 프로필과 빈 캐시, 배포물만 전달한 PC에서 네트워크 차단 후 첫 실행과 반복 실행을 비교한다. file://와 허용된 loopback 경로는 각각 별도 판정한다. 외부 요청 시도·CDN/인증/모델 다운로드 0, 사건자료 외부 전송 0을 합격 조건으로 제안한다. 다른 브라우저 통과는 업무 Edge 통과가 아니다.
