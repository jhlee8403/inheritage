## 원문 설명 / 외부 확인 / 영향

상실 관련 충돌의 원문·공식 URL은 SOURCE_REVIEW E-01~04를 기준으로 한다. 최신 1001에 상실 규정이 연결된 사실을 확인했으나, 모든 과거 개시 사건에 곧바로 적용한다는 결론은 내리지 않았다. R-14는 구법·신법·부칙 후보를 구분할 때까지 계산 보류 대상이다. 최신 1003·1010 전문과 경과규정 대조도 승인 대기다.

1005~1008의3은 법정 지분과 개별 권리·구체적 상속분을 구분하는 출처다. 특별수익·기여분·유류분·분묘 등 별도 계산 규칙을 이번 후보표에 몰래 포함하지 않았다. 한정승인은 포기와 다르게 표시하되 실제 책임 범위 판단은 자동화에서 제외한다.
