초기 M2의 공개 결과는 보수적인 전체 보류 계약을 제안한다: 필요한 규칙/날짜 승인 또는 사실/원장 무결성이 하나라도 부족하면 `BLOCKED`, 최종 allocations/paths 빈 목록, 미해결 Q 하나. 수치0 기장은 사람의 실체법상 지분0 판정이 아니다. E1의 검증된 역사 기록은 별도 감사 영역에 보존할 수 있지만 최종 합계에 중복 더하지 않는다.

ENGINE_DESIGN의 독립 가지 부분 보류는 유용한 후속 설계지만 현 C1 BLOCKED 계약과 다르므로 자동 채택하지 않는다. C의Q/2와 B가지 미해결Q/2를 정상/부분 결과로 게시하려면 별도 승인 계약이 필요하다. 이번 음성 시험은 전체 보류 방식으로 통일한다. 이 보수적 출력 정책은 법률 해석과 별도 승인 항목이다.

필수 provenance: rule ID/version·승인 기록 버전·법령 스냅샷·truth ID/version·사건 ID/개시일/기준일·관계 매개열·유입 경로·중간/말단 구별·Q·BLOCKED reason. 중복 ID 또는 서로 다른 ID로 재포장한 같은 실질 경로를 합산하지 않는다. 사실·관계·사건열·기준일·Q·법령·승인/규칙 버전 변경 시 전체 의존 스냅샷을 STALE로 만들고 복사를 즉시 막아야 한다. sum 검사와 사람/사건/경로 검사는 별개다.
