# 회사 Windows Edge 수동 시험 안내

이 통합 시제품의 Windows 실행은 NOT_RUN이다. 기존 C1 단독 HTML의 과거 사용자 확인을 이 파일의 합격으로 취급하지 않는다. 회사 반입·로컬 HTML/Blob worker/WASM 정책을 확인하고 허용된 경우만 시험한다. 정책 제한 시 중단하며 보안 옵션을 완화하지 않는다.

## 전달과 실행 (개발 도구 불필요)

개발 Mac에서 생성 완료된 다음 파일을 허용된 매체로 하나의 폴더에 복사한다.

- `generated/lite-v1.html` — 계산기·PDF.js·OCR worker/core/WASM·한국어 모델을 모두 포함한다.
- `generated/NOTICE.txt` — 재배포 출처·라이선스.
- 이 안내 문서 (`generated/Windows-시험안내.txt`에도 생성된다).
- 가공 시험 표본: 기존 `experiments/offline-ocr/fixtures/text-only.pdf`, `scan-only.pdf`와 새 `generated/fixtures/three-pages.pdf`. 실제 사건자료를 대신 넣지 않는다.

HTML의 기록된 SHA-256/바이트는 개발 보고서·results/build.json과 대조한다. HTML 파일을 Microsoft Edge 창에 끌어 놓거나 연결 프로그램을 Edge로 선택한다. 주소가 file:///...로 시작해야 한다. 인터넷·개발 Mac 서버·Node/npm/Python/Git/Codex 설치가 필요 없다. Mac 폴더 경로를 그대로 만들 필요도 없다.

회사 정책상 허용되는 실제 오프라인 조건에서 다음을 확인하고 날짜, Windows/Edge 버전, 실행한 HTML SHA, 성공/실패·오류 문구를 기록한다. 개발용 자동시험과 사용자 확인을 구분한다. 외부 요청 로그를 수집하지 않았다면 ‘외부 요청 0건 측정’으로 쓰지 않는다.

## 체크리스트

1. 첫 실행: 화면과 품질 경고가 표시되고 추가 다운로드가 없는지.
2. 가공 text-only.pdf 선택: 1/1 표시, 원문 렌더링, 직접 추출 NEEDS_REVIEW 후보.
3. scan-only.pdf 선택: 앞 문서 후보 제거, 직접 추출은 비어 있음, 명시적 ‘현재 페이지 한국어 OCR’ 실행 후 한국어 후보 생성. 이름 누락을 확인하고 원문과 대조하여 후보를 수정. 수정 후보가 계산 입력으로 자동 이동하지 않아야 함.
4. three-pages.pdf 선택: 1~3쪽 이동, 페이지별 후보가 섞이지 않는지. OCR 도중 이동·취소·다른 문서 선택 후 늦은 후보가 덮어쓰지 않는지.
5. C1 세 표본 계산: 배우자+자녀 W=3/7, C1/C2=2/7; 배우자+부모 W=3/7, F/M=2/7; 자녀 3명 각 1/3. 이는 가공 조건의 독립 비교값이며 일반 법률 범위가 아님.
6. Q 수정 즉시 이전 결과 제거와 복사 비활성화, 재계산 후 새로운 분수. 배우자 UNKNOWN은 BLOCKED/미해결 Q, 분모 0은 ERROR이며 이전 성공 결과가 남지 않는지.
7. 최신 결과 복사 후 메모장 붙여넣기. 자동 복사가 제한되면 ‘결과 텍스트 선택’ 후 Edge 복사 메뉴 또는 Ctrl+C. 입력 변경 후 과거 결과 복사 차단. 이미 외부에 붙여넣은 내용은 자동 회수하지 않음.
8. 문서 닫기: 원문·후보 제거. 종료 후 재열기 시 자동으로 이전 사건이 복원되지 않는지. 프로그램은 자동 저장하지 않지만 OS/브라우저의 swap·클립보드·복구 기능까지 안전 삭제한다고 보장하지 않음.
9. 지원 한도 초과/손상 PDF는 ERROR/TIMEOUT으로 중단하는지. 멈춘 경우 PDF/OCR 취소 또는 창 닫기 후 오류 단계/시간을 기록. 장시간 기다리거나 보안을 완화하지 않음.

## 사용 제한

가공 사례 검증 전용이다. 실제 사건 문서·개인정보 사용 금지. 현재 C1은 개시일 2017-01-10 / 기준일 2017-01-11 / BL1-LAW-2016-14409의 승인된 세 유형만 계산한다. R04/R05는 PENDING이며 과거법·입양·상속포기·복수 사건 등은 확대 지원하지 않는다.

한국어 단일 모델의 기존 고정 가공 표본 CER 32.84%와 인명 누락이 확인됐다. 한자·세로쓰기·복잡한 제적등본 정확도 합격이 아니다. 추출/OCR/사용자 수정 모두 NEEDS_REVIEW이며 법률 사실 확정이 아니다.
